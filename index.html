GHS 업로드 가이드

Final Cut 최종 라이브러리를 서버에 우클릭 한 번으로 올려요. 압축, 번호 붙이기, 업로드, 파일 검사까지 알아서 진행돼요.

설치

처음 한 번만
  1. ⬇ 설치 파일 받기 GHS업로드_설치.zip · 14KB
    받은 zip을 더블클릭해서 압축을 풀어요.
  2. 설치.command를 더블클릭해요.
    "Apple이 악성 코드가 없음을 확인할 수 없습니다" 창이 뜨면 정상이에요. 휴지통으로 이동은 누르지 말고 '완료(Done)'를 눌러요.
  3. 시스템 설정 → 개인정보 보호 및 보안을 열고 아래로 스크롤해서 '그래도 열기'를 눌러요. 비밀번호(또는 Touch ID)를 입력하고, 다시 뜨는 창에서 열기를 눌러요.
    '그래도 열기' 버튼은 차단된 뒤 약 1시간 동안만 보여요. 안 보이면 2번부터 다시 하세요.
  4. 터미널 창에 ✅ 설치 완료!가 뜨면 아무 키나 눌러 닫아요. Finder가 잠깐 다시 시작돼요.
시스템 설정이 어렵다면: 터미널로 설치하기

1. 터미널 앱을 열어요.

2. bash (bash 다음에 한 칸 띄우기)를 입력하고, Finder에서 설치.command를 터미널 창으로 끌어다 놓은 뒤 엔터를 쳐요.

올리는 방법

  1. 서버 연결: Finder에서 ⌘ K → smb://GHS → 회사 계정으로 로그인 → 1_GHS 선택
  2. 올릴 라이브러리만 닫기: Final Cut에서 파일 → 라이브러리 닫기
    Final Cut 자체는 켜 둬도 괜찮아요. 올리려는 라이브러리만 닫혀 있으면 돼요.
  3. Finder에서 .fcpbundle(보라색 별 아이콘)을 우클릭 → 빠른 동작 → GHS 업로드
    메뉴가 안 보이면 빠른 동작 → 사용자화…에서 'GHS 업로드'를 체크하세요. 여러 개를 한꺼번에 선택해도 하나씩 차례로 올라가요.
  4. 오른쪽 위 알림을 확인하면 끝이에요.
    ⏳ 압축 중…→ ⏳ 서버로 올리는 중…→ ✅ 업로드 완료

수정본 다시 올리기

같은 번호의 파일이 서버에 이미 있으면 "덮어쓸까요?" 창이 떠요. 덮어쓰기를 누르면 교체되고, 취소를 누르면 아무것도 바뀌지 않아요.

덮어쓰면 기존 파일은 남지 않아요 꼭 맞는 파일인지 확인하고 누르세요. 새 파일이 서버에 다 올라가고 검사까지 끝난 뒤에 기존 파일을 지우기 때문에, 업로드가 중간에 실패해도 기존 파일은 그대로 있어요.

자주 묻는 질문

Final Cut이 켜져 있으면 업로드가 안 되나요?

아니에요. Final Cut이 켜져 있어도 올라가요. 올리려는 그 라이브러리가 열려 있을 때만 멈춰요. 열린 채로 압축하면 저장 중인 상태로 압축돼서 서버에 깨진 라이브러리가 올라갈 수 있기 때문이에요.

Claude가 깔려 있어야 하나요?

아니요. macOS에 원래 있는 기능(빠른 동작)과 스크립트로만 동작해요.

얼마나 걸려요?

라이브러리 크기에 따라 달라요. 1GB 안팎이면 몇 분 걸려요. 끝나면 알림이 떠요.

업로드 기록은 어디서 봐요?

~/Library/Logs/GHS업로드.log에 남아요.

새 버전이 나오면 어떻게 해요?

새 GHS업로드_설치.zip을 받아서 같은 방법으로 다시 설치하면 덮어써져요.
